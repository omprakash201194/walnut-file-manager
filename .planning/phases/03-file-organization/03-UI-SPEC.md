Accent is NOT used for: informational text, file size labels, category headers, or decorative elements.

Category color coding (for the six file type categories in preview):
- Documents: no accent color — use `text-foreground` with a `lucide-react` icon
- Photos: no accent color — icon differentiation only
- Music: no accent color — icon differentiation only
- Video: no accent color — icon differentiation only
- Archives: no accent color — icon differentiation only
- Other: no accent color — icon differentiation only

Use shadcn `Badge` with `variant="secondary"` for category count chips. No per-category color coding in v1 — uniform secondary badge style maintains visual calm.

## State Machine

OrganizerPage states (mirrors Phase 2 `scanStatus` pattern):

| State | Trigger | UI Shown |
|-------|---------|----------|
| `no-scan` | Page load, no scan results in store | Empty state: "Scan a folder first" |
| `idle` | Scan results available, no preview generated | Strategy tabs + Preview button + empty preview area |
| `previewing` | Preview button clicked | Strategy tabs + loading indicator in preview area |
| `ready` | Preview data returned | Strategy tabs + accordion preview + Apply button enabled |
| `applying` | Apply button clicked | Apply button shows "Applying…" disabled; Undo hidden |
| `done` | Apply complete | Preview area shows confirmation; Undo button appears |
| `error` | Move failure during apply | Error area below action bar (dismissible) |

Undo availability: Undo button visible only when `organizerStatus === 'done'` AND undo stack has entries. Button shows timestamp of last apply.

## Interaction Contracts

### Strategy Tab Switching
- First visit: By Type tab active, preview area empty, Preview button enabled
- Click "Preview": generates preview for active strategy; status → `previewing` → `ready`
- Switch tab BEFORE first preview: no auto-preview; tab switches, preview area stays empty
- Switch tab AFTER first preview: auto-regenerates preview for new strategy (implicit re-preview, per D-04)
- Tab indicator: `border-b-2 border-blue-500` on active tab, `text-foreground`; inactive tab `text-muted-foreground`

### Preview Button
- Label: "Preview" (always, regardless of strategy)
- State: enabled in `idle` state; loading spinner + "Previewing…" label in `previewing` state
- Visual: `variant="default"` (white/light background) — not blue; blue is reserved for sidebar active state
- After first preview: button remains visible but becomes secondary — Apply takes visual precedence

### Apply Button
- Label: "Organize [N] files" where N is total file count across all categories
- Enabled: only in `ready` state (preview has been generated)
- Variant: `variant="destructive"` — file moves are irreversible without Undo
- Disabled state: `opacity-50 cursor-not-allowed` (shadcn default disabled styling)
- Loading state: "Organizing…" + disabled

### Undo Button
- Label: "Undo last reorganization · [timestamp]" (e.g., "Undo last reorganization · 2:34 PM")
- Variant: `variant="ghost"` — secondary action, not primary
- Visible: only when undo stack has entries (post-apply)
- Confirmation: no modal — single click triggers undo immediately (undo is always reversible, so no "are you sure" needed)
- Loading state: "Undoing…" + disabled

### Error Area
- Position: between preview area and action bar, or inline below action bar
- Pattern: dismissible `div` with `bg-destructive/10 border border-destructive/30 text-sm text-destructive rounded-md px-4 py-3`
- Dismiss: `X` button (same ghost button pattern as Sidebar protected folder removal)
- Content: "Could not move [N] file(s). Check that the files are not open in another program." — see Copywriting Contract

## Copywriting Contract

| Element | Copy | Notes |
|---------|------|-------|
| Primary CTA | "Preview" | Triggers dry-run categorization |
| Apply CTA | "Organize [N] files" | N = total file count; not "Apply" — more descriptive |
| Undo CTA | "Undo last reorganization · [time]" | Time = wall-clock time of last apply (12h format) |
| Empty state heading (no-scan) | "Scan a folder first" | Shown when no walkDirectory results in store |
| Empty state body (no-scan) | "Switch to Duplicates and run a scan — the results will be available here automatically." | Points user to existing scan flow (D-01: shared scan) |
| Empty state heading (idle, scan ready) | "Ready to organize" | Scan results exist, no preview yet |
| Empty state body (idle, scan ready) | "Choose a strategy and click Preview to see how your files will be arranged." | Guides first action |
| Preview section header | "[Category] — [N] files" | e.g., "Documents — 14 files"; category capitalized |
| Preview empty (no files in category) | Omit section entirely | Do not render empty accordion sections |
| Apply confirmation | None — no modal | Apply button label conveys the action; undo is available |
| Error state | "Could not move [N] file(s). Check that the files are not open in another program." | Dismissible inline area; N = failed count |
| Error state (partial success) | "Moved [success] of [total] files. [N] file(s) could not be moved — check for open files or permission issues." | When some succeed and some fail |
| Applying progress | "Organizing…" | Button label during apply; no separate progress bar needed in v1 |
| Undo success | (return to idle state with preview visible) | No toast — state change is sufficient feedback |
| Strategy tab: By Type | "By Type" | Default tab |
| Strategy tab: By Extension | "By Extension" | Secondary tab |
| Sidebar nav item | "Organizer" | Already established in Phase 1 (do not change) |

## Category Definitions (ORG-01)

Extension-to-category mapping (Claude's discretion, per CONTEXT.md):

| Category | Extensions | Icon (lucide-react) |
|----------|------------|---------------------|
| Documents | .pdf .doc .docx .xls .xlsx .ppt .pptx .odt .ods .odp .txt .rtf .md .csv .pages .numbers .key | `FileText` |
| Photos | .jpg .jpeg .png .gif .webp .heic .heif .bmp .tiff .tif .svg .ico .raw .cr2 .nef .arw | `Image` |
| Music | .mp3 .flac .aac .wav .ogg .m4a .wma .opus .aiff | `Music` |
| Video | .mp4 .mov .avi .mkv .wmv .flv .webm .m4v .mpg .mpeg .3gp | `Video` |
| Archives | .zip .rar .7z .tar .gz .bz2 .xz .iso .dmg .cab | `Archive` |
| Other | (all remaining extensions) | `File` |

"By Extension" strategy: creates one subfolder per extension (e.g., `/jpg/`, `/mp3/`), not grouped. Uses lowercase extension as folder name, no leading dot.

"By Type" strategy: creates one subfolder per category name (e.g., `/Documents/`, `/Photos/`).
