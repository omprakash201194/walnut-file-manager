<!-- Playwright for Electron API patterns from research. -->

Launching the app:
```typescript
import { test, expect, _electron as electron } from '@playwright/test'
import type { ElectronApplication, Page } from '@playwright/test'
import * as path from 'path'

let electronApp: ElectronApplication
let window: Page

test.beforeAll(async () => {
  electronApp = await electron.launch({
    args: [path.join(__dirname, '../out/main/index.js')],
  })
  window = await electronApp.firstWindow()
  await window.waitForLoadState('domcontentloaded')
})

test.afterAll(async () => {
  await electronApp.close()
})
```

Key Playwright selectors to use (based on Sidebar.tsx + page component text):
- Sidebar nav: `window.locator('text=Duplicates')`, `window.locator('text=Organizer')`
- Choose Folder button: `window.locator('aria-label=Choose folder to scan')` or `window.locator('text=Choose Folder')`
- Organizer page heading: `window.locator('text=File Organizer')` or similar (check OrganizerPage.tsx)
- Scan progress: `window.locator('[aria-live="polite"]')` or progress bar locator

IMPORTANT: Do NOT interact with the OS file picker dialog from Playwright — it is a native dialog that Playwright cannot control. Use a workaround: call `window.evaluate()` to set `selectedFolder` in the Zustand store directly, then trigger scan via keyboard/button if needed. Or use Playwright's `electronApp.evaluate()` to set the IPC state. For simplest happy-path tests, use `electronApp.evaluate()` to call the IPC channel directly.

Pattern for bypassing OS dialog in e2e:
```typescript
// Use electronApp.evaluate to call main-process logic directly
await electronApp.evaluate(async ({ ipcMain }) => {
  // not directly available this way
})
// OR: use window.evaluate to call window.api directly
await window.evaluate((folderPath) => {
  window.api.scanStart(folderPath)
}, 'C:\\Windows\\Temp')  // Use a small, real directory on the test machine
```
