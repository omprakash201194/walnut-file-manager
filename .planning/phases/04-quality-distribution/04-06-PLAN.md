**Setup — create temp folder with real files:**

Use `electronApp.evaluate` to run Node.js code in the main process. Create a temp folder with 3 files of different types so the organizer has something to move:

```typescript
const tmpDir = await electronApp.evaluate(async () => {
  const { mkdtemp, writeFile, mkdir } = await import('fs/promises')
  const { join } = await import('path')
  const { tmpdir } = await import('os')
  const dir = await mkdtemp(join(tmpdir(), 'walnut-e2e-org-'))
  await writeFile(join(dir, 'report.pdf'), 'pdf content')
  await writeFile(join(dir, 'photo.jpg'), 'jpg content')
  await writeFile(join(dir, 'notes.txt'), 'text content')
  return dir
})
```

**Scan the temp folder:**
1. Set timeout to 90000.
2. Navigate to Duplicates page: click `text=Duplicates`, wait for `text=Duplicate Files`.
3. Start scan: `window.evaluate((dir) => window.api.scanStart(dir), tmpDir)`.
4. Wait for scan complete: `window.locator('text=/Scan Again|No duplicates|duplicates found/i')` timeout 45000.

**Run organizer preview and apply:**
5. Navigate to Organizer: click `text=Organizer`.
6. Wait for Preview button: `window.getByRole('button', { name: 'Preview' })` visible with timeout 10000.
7. Click Preview button. Wait for `text=By Type` AND for the Preview button to re-enable (status returns from 'previewing' to 'ready'). Use `await expect(window.getByRole('button', { name: /Organize \d+ file/i })).toBeEnabled({ timeout: 15000 })`.
8. Note the Organize button label (to confirm files were previewed).
9. Click the Organize button: `window.getByRole('button', { name: /Organize \d+ file/i })`.
10. Wait for the Undo button to appear: `window.locator('button', { hasText: /Undo last reorganization/i })` visible with timeout 15000. This confirms Apply completed and status is 'done'.

**Verify undo:**
11. Click the Undo button: `window.locator('button', { hasText: /Undo last reorganization/i })`.
12. Wait for the Undo button to disappear: `await expect(window.locator('button', { hasText: /Undo last reorganization/i })).not.toBeVisible({ timeout: 15000 })`. This confirms orgUndo ran and the undo stack is now empty (or resetOrganizer was called).
13. Verify organizer returned to idle state: `window.getByRole('button', { name: 'Preview' })` is visible again.
