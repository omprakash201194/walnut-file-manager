| Token | Value | Usage |
|-------|-------|-------|

| sm | 8px | File row internal padding, badge margin, checkbox gap |
| md | 16px | Card padding, section padding, accordion item padding |
| lg | 24px | Summary bar padding, page content top padding |
| xl | 32px | Progress view vertical rhythm |

| 3xl | 64px | Page-level bottom clearance above sticky panel |

Exceptions:
- Sticky bottom delete panel: 72px bottom clearance on page content (panel height = ~64px + 8px gap)
- Touch/click targets on checkboxes: minimum 24px × 24px (Radix Checkbox default — do not reduce)

## Component Visual Contracts

### DuplicatesPage — Three Exclusive States

The page renders exactly one state at a time. No mixed-state rendering.

#### State 1: Empty (no folder selected, or results cleared)

Layout: centered vertically and horizontally in the content area.

```
[Files icon, 48px, text-muted-foreground]
"No folder selected"                    ← Heading (20px, semibold, foreground)
"Choose a folder from the sidebar       ← Body (14px, muted-foreground)
 to scan for duplicate files."
```

No CTA button in the empty state — the sidebar's "Choose Folder" button is the action path.

#### State 2: Scanning (full-page progress view)

Layout: centered vertically in the content area with a max-width of 480px centered horizontally.

```
[Folder path, 12px label, muted-foreground, truncated]

[Progress bar — full width, blue-500 fill, height 8px]

Files scanned: 1,243 / 4,891                    ← 14px body
Elapsed: 0:12                                    ← 14px body
Duplicates found: 7                              ← 14px body, accent if > 0
Current file: C:\Users\...\filename.jpg          ← 12px label, muted, truncated

[Cancel Scan button — outline variant, full width, 36px height]
```

Progress bar uses `shadcn Progress` with `value` prop (0–100). Show indeterminate state (animated pulse) until file total is known (first progress event received).

#### State 3: Results

Layout: scrollable content with sticky bottom panel.

**Summary bar** (top of results, not scrolling away — use `sticky top-0 z-10 bg-background`):
```
X duplicates found — you can reclaim Y GB     ← 14px body, foreground
[Keep Newest]  [Keep Oldest]                  ← sm buttons, outline variant, blue-500 border+text
```

**Duplicate group list** (scrollable via ScrollArea):
- Each group: shadcn Accordion item
- Collapsed header: `[filename] · N copies · X.X MB total` — 14px semibold filename, 12px muted remainder
- Expanded rows: one FileRow per copy

**FileRow layout** (horizontal flex, full width):
```
[Checkbox 20px]  [Path truncated flex-1]  [Size 64px right-align]  [Date 96px right-align]  [KEEP badge or spacer]
```

- Checkbox: 20px × 20px, 8px gap to path
- Path: `text-sm text-foreground` when checked, `text-sm text-muted-foreground` when unchecked
- Size: `text-xs text-muted-foreground`, right-aligned
- Modified date: `text-xs text-muted-foreground`, format `MMM D, YYYY`, right-aligned
- KEEP badge: `bg-emerald-500/20 text-emerald-400 text-xs font-medium px-2 py-0.5 rounded-full` — visible on currently-preserved copy only; updates in real-time on preset change

**Sticky bottom panel** (DeletePanel):
- Position: `fixed bottom-0 left-[220px] right-0` (220px = sidebar width)
- Background: `bg-card border-t border-border`
- Padding: `px-6 py-4`
- Height: ~64px
- Animation: `translate-y-full` → `translate-y-0` with `transition-transform duration-200` when selection count goes 0→1; reverses when count goes to 0
- Layout: `flex items-center justify-between`

```
[Left] N files selected · X.X MB to free     ← 14px body, foreground
[Right] [Delete N files → Trash button]       ← destructive variant, h-9
```

- Button label updates dynamically with exact count and size
- Button uses shadcn Button `variant="destructive"` (red-500 background)
- No confirmation dialog — the panel text is the preview (SAFETY-01) and the button click is the confirmation (SAFETY-03)

### Sidebar Additions (Phase 2)

Below the existing "Choose Folder" / path display section, after a Separator:

**Protected Folders section:**
```
Protected folders                             ← 12px label, muted-foreground
[+ Add current folder as protected]           ← ghost button, xs size, full width
[Listed protected folders, each with × remove] ← 12px label, foreground + ghost icon button
```

- Label: "Protected folders" at 12px weight 400, muted-foreground
- "Add" button: ghost variant, xs size, left-aligned icon (ShieldCheck or Lock from Lucide, size-3)
- Protected folder entries: 12px truncated path + `×` ghost icon button (size-3) on the right
- If no protected folders: show "None" in 12px italic muted-foreground

## Interaction States

### Checkbox (FileRow)

| State | Visual |
|-------|--------|
| Unchecked | Radix default — zinc-700 border, transparent fill |
| Checked | blue-500 fill, white checkmark |
| Disabled (keep-at-least-one) | Opacity 50%, pointer-events none — last unchecked copy in a group cannot be checked |
| Hover (unchecked) | zinc-600 border |

The keep-at-least-one constraint (SELECT-02): when only 1 copy remains unchecked in a group, that copy's checkbox is `disabled`. Visual cue: the row has `opacity-50` applied and a tooltip "Cannot remove last copy" on hover.

### Accordion Group Card

| State | Visual |
|-------|--------|
| Collapsed | `bg-card border border-border rounded-lg` — zinc-900 card, zinc-700 border |
| Expanded | `bg-card border border-blue-500/30 rounded-lg` — subtle blue border to indicate active |
| Hover (header) | `bg-muted/50` on header row |
| First group on load | Expanded by default (D-09) |

### Scan Progress Bar

| State | Visual |
|-------|--------|
| Indeterminate (walk phase) | Animated shimmer pulse across full width — use `animate-pulse` on a gradient |
| Determinate (hash phase) | Filled left-to-right, blue-500 fill, smooth transition |
| Complete | 100% fill, immediately transitions to results view |

### Delete Panel

| State | Visual |
|-------|--------|
| Hidden (0 files selected) | `translate-y-full` — fully off-screen below viewport |
| Visible (≥1 file selected) | `translate-y-0` — slides up, 200ms ease-out |
| Button hover | `bg-destructive/90` |
| Button active | `bg-destructive/80` |
| Post-deletion | Panel hides (selections cleared), results refresh to remove deleted files |

## Accessibility Contract

- `Progress` component: `role="progressbar"` with `aria-valuenow`, `aria-valuemin="0"`, `aria-valuemax="100"`, `aria-label="Scan progress"` — Radix Progress provides this automatically
- `Accordion`: keyboard navigation (Enter/Space to expand, Arrow keys between items) — Radix Accordion default
- `Checkbox`: `aria-label` = full file path for screen readers (not just the visible truncated text)
- Delete panel: `aria-live="polite"` on the count/size text so selection changes are announced
- Summary bar: `aria-live="polite"` on the space savings figure so it announces when scan completes
- Cancel button: `aria-label="Cancel current scan"` (supplements visible text)
- Keep badge: `aria-label="This copy will be kept"` on each KEEP badge element
