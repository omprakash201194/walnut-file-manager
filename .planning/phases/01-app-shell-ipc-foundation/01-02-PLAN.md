       - Button onClick handler:
         ```typescript
         const [isPickerOpen, setIsPickerOpen] = useState(false);
         const setSelectedFolder = useAppStore((s) => s.setSelectedFolder);

         const handleChooseFolder = async () => {
           setIsPickerOpen(true);
           try {
             const folder = await window.api.selectDirectory();
             if (folder) {
               setSelectedFolder(folder);
             }
           } catch {
             // IPC error — could show toast, but for Phase 1 just log
             console.error('Failed to open folder picker.');
           } finally {
             setIsPickerOpen(false);
           }
         };
         ```
       - Button disabled state: `disabled={isPickerOpen}` — prevents duplicate IPC calls while OS dialog is open (per UI-SPEC interaction states and CONTEXT.md specifics)
       - Path display below button: `<p aria-live="polite">` for screen reader announcements
         - No folder: "No folder selected" in `text-xs text-muted-foreground italic`
         - Folder selected: Show path in `text-xs text-zinc-200 truncate` — use CSS `direction: rtl` + `text-overflow: ellipsis` to truncate from the LEFT (showing the end of the path, e.g., `...Users\name\Documents`)

       **Sidebar container:**

       - Full height: `h-screen`
       - Background: `bg-card` (zinc-800 equivalent via shadcn token)
       - Flex column: `flex flex-col`

       import DuplicatesPage from './pages/DuplicatesPage';

             </Routes>

       }
