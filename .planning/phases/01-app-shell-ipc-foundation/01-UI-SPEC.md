# Phase 1 — UI Design Contract

> Visual and interaction contract for Phase 1: App Shell & IPC Foundation.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.

---

## Scope

Phase 1 delivers the Electron app shell: a dark-mode window, sidebar navigation
(Duplicates, Organizer), a folder picker button with selected path display, and
placeholder content views for each module. There are no data-driven lists, no
destructive actions, and no scan operations in this phase.

Requirements covered: SHELL-01, SHELL-02, SHELL-03.

---

guide) for Electron compatibility.

## Layout

### App Shell Structure

```
+---------------------------+----------------------------------+
| Sidebar (220px fixed)     | Main Content Area (flex-1)       |
|                           |                                  |
| [App logo / name]         | [Module placeholder content]     |
| ───────────────           |                                  |
| > Duplicates  (nav item)  |                                  |
| > Organizer   (nav item)  |                                  |
|                           |                                  |
| ───────────────           |                                  |
| [Folder picker area]      |                                  |
|   Selected path display   |                                  |
+---------------------------+----------------------------------+
```

- Sidebar: fixed 220px, full viewport height, dark surface (secondary color)
- Main content: fills remaining space, scrollable independently
- No header bar — sidebar-left layout only
- Window drag region: custom titlebar is not required in Phase 1; use default Electron frame

### Sidebar Anatomy

1. App identity area (top, 64px height): app name "Walnut" in heading size
2. Navigation group: stacked nav items for Duplicates and Organizer
3. Folder picker area (bottom of sidebar, pinned): "Choose Folder" button + selected path text below it

Active nav item: accent left-border (4px) + accent text color.
Inactive nav item: muted text, no border. Hover: subtle background highlight (secondary + hover state).

## Color

Zinc dark scale (shadcn default for dark-mode-first apps).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | hsl(240 10% 4%) — zinc-950 | App background, main content area surface |
| Secondary (30%) | hsl(240 4% 16%) — zinc-800 | Sidebar surface, card backgrounds |
| Accent (10%) | hsl(217 91% 60%) — blue-500 | See reserved-for list below |
| Destructive | hsl(0 84% 60%) — red-500 | Not used in Phase 1 (no destructive actions) |

Accent reserved for:
- Active sidebar navigation item (left border + text)
- "Choose Folder" button (primary CTA — filled button)
- Focus rings on interactive elements (keyboard nav)

All other interactive elements (inactive nav items, non-primary buttons) use zinc
muted tones, not accent. Do not use accent for decorative purposes.

Muted text: `hsl(240 5% 65%)` — zinc-400. Used for selected path display when no
folder is selected, placeholder body text.

Border color: `hsl(240 4% 22%)` — zinc-700. Used for sidebar separator, card outlines.

## Interaction States

### Folder Picker Button ("Choose Folder")

| State | Visual |
|-------|--------|
| Default | Accent-filled button, white label |
| Hover | Accent color at 90% opacity (shadcn button hover default) |
| Active/pressed | Accent color at 80% opacity |
| Loading | Button disabled + cursor not-allowed (while dialog is open, prevent double-invoke) |
| Error | Button returns to default; error toast or inline message shown |

The folder picker invokes `window.api.selectDirectory()` via IPC. While the OS
dialog is open, the button must be disabled to prevent duplicate IPC calls.

### Sidebar Navigation Items

| State | Visual |
|-------|--------|
| Default | zinc-400 text, no background |
| Hover | zinc-800 background, zinc-100 text |
| Active (current route) | 4px accent left border, accent text color, zinc-800/50 background |
| Focus (keyboard) | Focus ring: accent color outline-2 offset-1 |

### Selected Path Display

| State | Visual |
|-------|--------|
| No folder selected | "No folder selected" — zinc-400 muted text, italic |
| Folder selected | Full path in zinc-200, truncated at start with `…` if longer than sidebar width |

## Accessibility

- All interactive elements must have visible focus rings (keyboard navigation)
- Sidebar nav items: `aria-current="page"` on the active item
- Folder picker button: `aria-label="Choose folder to scan"`
- Selected path: wrapped in `<p aria-live="polite">` to announce updates to screen readers
- Minimum contrast ratio: 4.5:1 for all text against background (WCAG AA)
  - zinc-400 on zinc-950 passes at ~4.6:1
  - zinc-200 on zinc-800 passes at ~7.2:1
- Window minimum dimensions (900×600) prevent layout collapse
