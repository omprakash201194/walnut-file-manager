    1. Create `shared/ipc-types.ts` (per D-01, D-02). This file establishes the project-wide IPC convention. Channel naming uses descriptive colon-separated strings (per CONTEXT.md specifics):
       ```typescript
       // IPC Channel Constants
       // Convention: 'domain:action' naming. Add new channels here as the app grows.
       export const IPC_CHANNELS = {
         SELECT_DIRECTORY: 'dialog:select-directory',
       } as const;

       // Typed API exposed to renderer via contextBridge
       export interface IpcApi {
         selectDirectory: () => Promise<string | null>;
       }

       // Augment Window type so renderer code gets type-safe access
       declare global {
         interface Window {
           api: IpcApi;
         }
       }
       ```

    2. Update `src/main/index.ts` to register the IPC handler (per D-01, D-02). Keep the existing electron-vite template BrowserWindow setup. Add the IPC handler registration:
       - Import `ipcMain` and `dialog` from `electron`
       - Import `IPC_CHANNELS` from `../../shared/ipc-types`
       - Register handler: `ipcMain.handle(IPC_CHANNELS.SELECT_DIRECTORY, async (event) => { ... })`
       - Handler body: get BrowserWindow from `event.sender`, call `dialog.showOpenDialog(window!, { properties: ['openDirectory'] })`, return `result.filePaths[0]` or `null` if canceled
       - Ensure BrowserWindow webPreferences has: `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true` (per D-02)
       - Set window dimensions: `width: 1100, height: 700, minWidth: 900, minHeight: 600` (per UI-SPEC)
       - Keep `show: false` + `ready-to-show` pattern from template

    3. Update `src/preload/index.ts` to expose the typed API (per D-01, D-02). Replace the template preload content:
       ```typescript
       import { contextBridge, ipcRenderer } from 'electron';
       import { IPC_CHANNELS } from '../../shared/ipc-types';

       contextBridge.exposeInMainWorld('api', {
         selectDirectory: (): Promise<string | null> =>
           ipcRenderer.invoke(IPC_CHANNELS.SELECT_DIRECTORY),
       });
       ```
       Do NOT expose raw `ipcRenderer`. Do NOT create a generic `send(channel, ...args)` function. One function per operation.

    4. Create `src/renderer/src/store/appStore.ts` (per D-03):
       ```typescript
       import { create } from 'zustand';

       interface AppState {
         selectedFolder: string | null;
         setSelectedFolder: (folder: string | null) => void;
       }

       export const useAppStore = create<AppState>()((set) => ({
         selectedFolder: null,
         setSelectedFolder: (folder) => set({ selectedFolder: folder }),
       }));
       ```
